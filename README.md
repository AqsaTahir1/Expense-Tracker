
# Expense Tracker

A full-stack web application for managing personal finances.
Users can record income and expenses, monitor their balance,
and visualize their spending through interactive charts.

## Features

- User registration and login
- JWT-based authentication
- Protected dashboard
- Add, edit and delete transactions
- Income and expense tracking
- Automatic balance calculation
- Transaction search and filtering
- Monthly financial summary
- Interactive charts
- Responsive user interface
- User-specific transaction management

## Installation

### 1. Clone the repository

git clone (https://github.com/AqsaTahir1/Expense-Tracker)

### 2. Backend setup

cd backend
npm install

Create a .env file using .env.example
and configure your database connection and JWT secret.

Start the backend using the start command
defined in package.json.

### 3. Frontend setup

Open another terminal:

cd frontend
npm install

Create a .env file using .env.example.

Start the frontend:

npm run dev
